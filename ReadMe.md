# PixRecorder

With the PixRecorder you can synchronize your favourite music with pictures, art and graphics.
The tool modulates tone and image to create reorganized projections based on the music.

Originally created in the early 2000s as a Macromedia Director project, PixRecorder was rebuilt as a browser application in 2026. 
The project runs entirely in the browser as a single self-contained HTML file. The current browser implementation is a modern reimagining using standard web technologies while preserving the original creative vision.

Originally designed and developed by Markus Remscheid / [H2D2](https://www.h2d2.de).
